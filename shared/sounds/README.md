# Свої звуки

Поклади сюди файли `.mp3` або `.m4a` — і гра заграє їх замість вбудованого синтезу. Код міняти не треба.

Імена звуків: `move`, `capture`, `check`, `wrong`, `right`, `star`, `win`, `lose`, `level`, `oink`, `oy`
(наприклад, `capture.mp3`).

Голос (грається додатково, трохи після звуку): `right-voice.mp3`, `wrong-voice.mp3`, `win-voice.mp3`.

Яких файлів немає — для тих грає синтез. Докладніше — розділ «Звуки» в `CLAUDE.md`.
