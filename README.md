# Chess-games

Невеликі навчальні сторінки для учнів шахової школи [yaroslavchess.com](https://yaroslavchess.com).
Кожна сторінка — окремий файл `index.html`, збирати нічого не потрібно.

| Сторінка | Що це |
|---|---|
| [`knight-quest/`](knight-quest/index.html) | «Хід Конем» — довести коня до цілі, обходячи заблоковані поля. 10 рівнів, лічильник ходів і часу, рекорди. Українською. |
| [`english/unit2/`](english/unit2/index.html) | Тренажер англійської «Unit 2: In the Spotlight»: слова, порівняння, прислівники, словосполучення. Англійською, з перекладом німецькою. |

## Як відкрити

Відкрийте потрібний `index.html` у браузері. Або з кореня репозиторію:

```
python3 -m http.server 8000
```

і перейдіть на `http://localhost:8000/knight-quest/` чи `http://localhost:8000/english/unit2/`.

## Приватність

Персональні дані не збираються. «Хід Конем» зберігає в браузері лише прогрес і рекорди
(`localStorage`) і підвантажує шрифти Google Fonts. Тренажер англійської нічого не
зберігає.
