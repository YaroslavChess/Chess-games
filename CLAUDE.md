# CLAUDE.md

Шахові міні-ігри для учнів Ярослава (діти 4–15 років і дорослі, українською).
Хостинг — GitHub Pages з гілки `main`: `https://yaroslavchess.github.io/Chess-games/<папка>/`.
Власник не програміст: він сам мерджить PR і сам читає та правити код. Тому код має бути простим.

## Структура

- Кожна гра — окрема папка (малі літери, через дефіс, напр. `knight-quest`) з **одним**
  `index.html` (HTML + CSS + JS в одному файлі).
  **Виняток:** кожна гра підключає спільну тему одним рядком
  `<script src="../theme/theme.js"></script>` (у `<head>`, після `<style>`) і бере кольори **лише зі змінних
  `:root`**: жодних `#...` і `rgba(...)` у CSS, крім чорних тіней `rgba(0,0,0,..)`. Якщо файл теми не
  завантажився, гра має працювати як раніше. Як додати тему — `theme/README.md`.
- Без збірки, без npm, без пакетів. Бібліотеки — лише з CDN (cdnjs / jsdelivr / unpkg)
  **з фіксованою версією** (не `latest`, не `@1`).
- Каталог — `index.html` у корені. Він уже знає всі ігри (масив `GAMES` на початку скрипту) і
  сам ховає картки ігор, яких ще немає (404). Тему він підключає як `./theme/theme.js`.
  **Каталог не правити**, якщо задача не про нього.
- Не чіпати папку `english/` та інші ігри, якщо задача не про них.

## Код

- Класичний JS: `function`, `var`/`let`, склеювання рядків через `+`. **Без** стрілкових
  функцій (`=>`), шаблонних рядків (зворотні лапки), класів і ES-модулів. Власник має могти
  сам прочитати й виправити код.
- Логіка дошки окремо від малювання. У коді координати завжди з боку білих (a1 — внизу
  ліворуч для білих); переворот дошки робиться **лише при відображенні**.
- Для стандартних шахових правил — лише перевірена бібліотека: **chess.js 0.10.3 з cdnjs**
  (глобальний `Chess`). Власний рушій стандартних правил не писати. Для нестандартних дошок і
  правил — власна логіка, покрита тестами.
- Рекорди й прогрес — `localStorage`; **кожне** читання й запис у `try/catch`. Гра має
  працювати й без нього (приватний режим, заборонене сховище).

## Інтерфейс

- Українською. Короткі фрази, великі кнопки.
- Працює на телефоні, планшеті й ноутбуці. Перевіряти на ширині 375 px: без горизонтального
  скролу.
- Керування тапом: тап по фігурі, тап по клітинці. Перетягування — бонус, не обов'язково.
- Стиль як у `knight-quest/index.html`: ті самі шрифти (Fraunces, Manrope, JetBrains Mono з
  Google Fonts — єдиний дозволений зовнішній стиль, крім шрифту заголовків у
  `theme/themes/*.css`) і CSS-змінні в `:root` — копіювати звідти, нових кольорів не вигадувати.
- Похвала у відгуках — за спосіб і старання («перевірив усі взяття», «не здався», «шукав далі»),
  а не за здібності. Не писати «ти розумний», «геній», «талановитий».

## Приватність

- Без реєстрації, реклами, аналітики й трекерів.
- Назовні нічого не надсилати. Єдиний виняток — онлайн-режим через Ably у тих іграх, де про
  нього прямо сказано в завданні.

## Онлайн-режим (лише де просить завдання)

- Ably JS SDK з офіційного CDN (з фіксованою версією). Ключ — константа на початку скрипту:

  ```
  var ABLY_KEY = 'HKRVtg.MscH2Q:AW1i-UndGu03DiHJOQ4M4j47m6R_exbbyt2P9GcF95U';
  ```

- Сценарій: вчитель натискає «Грати онлайн» → отримує посилання `?room=<випадковий id>` →
  кидає учню в чат Google Meet → учень відкриває і **одразу** грає іншим кольором, з
  перевернутою дошкою.
- «Ще раз» скидає партію в тій самій кімнаті, без нового посилання.
- Після оновлення сторінки гравець повертається в партію (id кімнати з URL, колір і позицію
  відновлювати з `localStorage` у `try/catch` та/або з історії каналу Ably).

## Перед PR

1. Прогнати логіку тестовим скриптом у node. Скрипт **не комітити**.
2. Відкрити сторінку в headless-браузері, якщо він доступний, і переконатися, що в консолі
   немає помилок; перевірити ширину 375 px, також з `?theme=halloween` і `?theme=winter`.
3. `grep -n "=>" <папка>/index.html` нічого не знаходить; у файлі немає зворотних лапок.
4. Один PR у `main` на завдання. Опис PR — українською: що зроблено, посилання, за яким гра
   відкриється після мерджу (`https://yaroslavchess.github.io/Chess-games/<папка>/`), що не
   вдалося перевірити.
