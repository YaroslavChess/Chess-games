# Автоматичний збір результатів у Google-таблицю

Тренажер (`english/unit2/index.html`) може непомітно для учня надсилати відповіді
та підсумки сесій у вашу Google-таблицю.

## 1. Підготуйте таблицю і скрипт

1. Створіть нову Google-таблицю (або відкрийте наявну).
2. Меню **Розширення → Apps Script**.
3. Видаліть код за замовчуванням і вставте весь вміст файлу [`apps-script.gs`](apps-script.gs).
4. Натисніть **Зберегти** (іконка дискети).

Аркуші **«Відповіді»** і **«Сесії»** створюються автоматично при першому надсиланні.

## 2. Розгорніть як Web app

1. **Розгорнути → Нове розгортання** → шестерня біля «Тип» → **Веб-застосунок**.
2. **Execute as / Виконувати від імені:** *Me / Я*.
3. **Who has access / У кого є доступ:** *Anyone / Усі*.
4. Натисніть **Розгорнути** і надайте дозволи (Google попередить, що застосунок не перевірений:
   **Додатково → Перейти до проєкту → Дозволити**).
5. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`).

Перевірка: відкрийте цей URL у браузері, має з'явитися текст
`Chess-games results endpoint is running.`

> Після кожної зміни коду скрипта потрібно зробити **Розгорнути → Керувати розгортаннями →
> Редагувати → Нова версія**, інакше діятиме стара версія.

## 3. Підключіть URL до тренажера

У `english/unit2/index.html` на початку скрипта знайдіть рядок

```js
const SHEET_URL = '';
```

і вставте свій URL:

```js
const SHEET_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
```

Поки константа порожня, нічого не надсилається. Закомітьте й запуште зміну.

## 4. Посилання для учнів

Ім'я учня береться з параметра `?s=`:

```
https://<ваш-сайт>/english/unit2/index.html?s=Anna
```

Без параметра ім'я буде `student`.

## Що записується

- **Відповіді** — одразу після кожної відповіді: час, учень, вкладка, налаштування,
  питання, відповідь учня, правильна відповідь, правильно/неправильно.
- **Сесії** — дата, учень, вкладка, Scope, Direction, Input Method, тривалість (с),
  пройдено карток (кількість відповідей, з повторами), точність, список помилок з кількістю,
  статус. Рядок з'являється на фінальному екрані («завершено») або при закритті/перезавантаженні
  сторінки чи зміні вкладки/налаштувань посеред сесії («перервано»).

Якщо надсилання не вдалося (немає інтернету, неправильний URL), тренажер працює як звичайно.
